# Fantasy Draft Assistant V1

Built for:
- 12 teams
- 0.5 PPR
- QB 1, RB 2, WR 2, TE 1, FLEX 1, DEF 1, K 1
- 6 bench spots
- Yahoo
- Draft: Aug 23, 2026 at 3:30 PM PT

## Free deployment
Use GitHub + Cloudflare Pages. Upload the four files in this folder to a GitHub repository, then connect the repo to Cloudflare Pages. No build command is required.

## Important
This is V1. The player list is a starter dataset. Before the real draft, we should replace it with current 2026 projections, ADP, injury/news and Yahoo-specific roster data.
